<h2>🚀 Project Overview</h2>

<p>
The BMI Calculator is an Android application that calculates 
Body Mass Index (BMI) using user-provided height and weight.
</p>

<p>
The app instantly displays the BMI value along with the 
corresponding health category such as Underweight, Normal, 
Overweight, or Obese.
</p>

<p>
This project demonstrates strong understanding of Android UI design, 
event handling, input validation, and activity lifecycle management.
</p>

<hr>

<h2>✨ Key Features</h2>

<ul>
  <li>Real-time BMI Calculation</li>
  <li>User Input Validation</li>
  <li>Health Category Classification</li>
  <li>Clean & Responsive UI</li>
  <li>Lightweight & Fast Performance</li>

<h2>🏗️ Application Architecture</h2>

<pre>
            ┌────────────────────┐
            │     User Interface │
            │   (XML Layout UI)  │
            └─────────┬──────────┘
                      │
                      ▼
            ┌────────────────────┐
            │   MainActivity     │
            │ (Business Logic)   │
            └─────────┬──────────┘
                      │
                      ▼
            ┌────────────────────┐
            │  BMI Calculation   │
            │     Formula        │
            └────────────────────┘
</pre>

<h4>Architecture Flow:</h4>
<ul>
  <li>User enters height and weight</li>
  <li>Button click triggers calculation</li>
  <li>BMI formula applied: weight / (height × height)</li>
  <li>Result displayed with health category</li>
</ul>

<h2>📱 Formula Used</h2>

<pre>
BMI = Weight (kg) / Height² (m²)
</pre>

<h4>Health Categories:</h4>

<ul>
  <li>Underweight: BMI less than 18.5</li>
  <li>Normal: BMI 18.5 – 24.9</li>
  <li>Overweight: BMI 25 – 29.9</li>
  <li>Obese: BMI 30 and above</li>
</ul>
